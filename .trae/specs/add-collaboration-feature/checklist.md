# Checklist

- [x] 顶栏"更多"下拉菜单下存在"协作"入口，且包含"发起协作"与"加入协作"两个子菜单项
- [x] 未协作状态下，"更多"菜单显示"协作 → 发起协作 / 加入协作"
- [x] 发起协作界面可输入密码、端口号，并勾选权限（添加扩展/删除扩展/删除角色等）
- [x] 发起协作成功后，发起者顶栏最左侧显示"协作中-管理员-在线人数 : N"
- [x] 发起协作成功后，"协作"按钮文字变为"结束协作"
- [x] 端口被占用时提示"端口被占用，请更换端口"，且不启动协作
- [x] 密码为空时阻止发起并提示"请设置密码"
- [x] 加入协作界面可输入 IP 与密码
- [x] 加入协作成功后，参与者顶栏最左侧显示"协作中-参与者"
- [x] 加入协作成功后，"协作"按钮文字变为"退出协作"
- [x] 密码错误时提示"密码错误，加入失败"
- [x] 目标 IP 不可达或端口未开放时提示"无法连接到目标主机"
- [x] 点击顶栏协作状态按钮可打开聊天区
- [x] 聊天区 UI 参考 iOS 风格：圆角气泡、本人消息右侧、他人消息左侧、毛玻璃背景
- [x] 发送消息后以右侧气泡显示并广播给所有协作者
- [x] 接收消息以左侧气泡显示并包含发送者标识
- [x] 发起者点击"结束协作"后关闭服务器并断开所有参与者
- [x] 参与者点击"退出协作"后断开连接，发起端在线人数减一
- [x] 发起者结束协作时，所有参与者收到"协作已结束"通知并被退出协作状态
- [x] 参与者在未授权操作（如删除角色）时被拦截并提示"无权限执行此操作"
- [x] 发起者本地操作不受权限限制
- [x] `tw-collaboration` 协议已注册并可加载协作窗口页面
- [x] 协作窗口 preload 已暴露所需 IPC API
