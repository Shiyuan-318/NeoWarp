隐私政策

更新于 2026 年 7 月 20 日

NeoWarp 是基于 TurboWarp Desktop 二次开发的离线编辑器。TurboWarp 完整的隐私政策可在 turbowarp.org/privacy.html 查看，本页面仅就桌面端相关的部分进行说明。

更新检查

NeoWarp 桌面端内置更新检查功能，可在桌面设置中关闭。关闭后，应用不会主动连接服务器检查新版本。

滥用防护

当服务遭到滥用时，我们可能采取措施收集必要信息以保护服务。例如，我们可能会记录发起过量请求的 IP 地址。我们会谨慎处理，尽量避免误伤正常用户。相关数据仅在停止滥用行为所需的时间内保留。

Rich Presence（在线状态展示）

桌面端提供「Rich Presence」功能（默认关闭）。启用后，会将当前打开的项目名称及已打开时长共享给运行于本机的聊天软件，并可能显示在您的公开状态中。此功能可在桌面设置中配置。

加载项目

当您从其他网站加载项目时，将受该网站隐私政策的约束。例如从 Scratch 加载项目时，您将受 Scratch 隐私政策的约束。具体来说，加载 Scratch 项目时，由于 Scratch 的部分 API 不允许直接访问，项目 ID 也会被发送给 TurboWarp。我们可能短暂记录项目 ID 用于缓存。

云变量

当连接云变量服务器时，项目 ID 和用户名可能会被记录 14 天。云变量中的数据是公开的，会发送给所有同时在线的其他用户。自定义云变量服务器不在我们的控制范围内。

扩展

部分扩展需要与外部 API 通信才能工作。例如翻译和文本转语音扩展依赖 Scratch API，受 Scratch 隐私政策约束。为提升性能，部分扩展会访问 TurboWarp 的 API，其中请求内容及转发到 Scratch 后的结果都可能被缓存。

官方扩展库中的大多数扩展，在项目尝试访问不受信任的网站时会询问权限，但我们无法保证 100% 可靠。

从官方扩展库以外位置（如 URL 或本地文件）加载自定义扩展时，编辑器会询问是否允许加载。一旦批准，该扩展可绕过官方扩展所展示的权限询问对话框。

NeoWarp 打包工具

集成的 NeoWarp 打包工具可能从 TurboWarp 控制的服务器下载文件（例如 Electron 二进制文件）。下载完成后这些文件会被缓存。

使用自定义扩展打包项目时，打包工具可能会访问相应网站下载扩展。

打包后的项目

打包后的项目包含运行所需的全部脚本、造型和声音。打包工具会尽量包含所有自定义扩展，但在某些情况下，打包后的项目每次运行时仍需下载某些扩展。

第三方自定义扩展、自定义云主机、自定义 JS、自定义 CSS 等高级功能不在我们的控制范围内。

请注意，与 TurboWarp 编辑器不同，打包项目中的自定义扩展在联系网站前不会询问权限。

您有责任告知最终用户您所分发文件的隐私实践。请勿将本页面作为您项目的隐私政策链接，因其可能随时变更，您需自行撰写。

本地数据

NeoWarp 作为桌面应用，您的项目文件、设置和缓存均保存在本地计算机上。除非您主动通过上述网络功能（如加载在线项目、连接云变量服务器等）发起请求，否则应用不会向服务器发送您的项目内容。

AI 编程助手功能：使用 AI 助手时，您输入的对话内容和项目结构信息会发送给您配置的 AI 服务提供商（如 DeepSeek）。这些数据的处理受相应服务提供商隐私政策约束。

Privacy Policy

Updated July 20, 2026

NeoWarp is an offline editor built on top of TurboWarp Desktop. The comprehensive privacy policy for TurboWarp can be found at turbowarp.org/privacy.html. Here, we have simplified it down to just the parts relevant to the desktop app.

Update Checker

The NeoWarp desktop app contains an update checker which can be disabled in desktop settings. When disabled, the app will not proactively contact the server to check for new versions.

Abuse

When a service is being abused, we may take measures to collect information to protect the service. For example, we could log IP addresses making excessive amounts of requests. We strive to do this carefully so that no one is caught in the crossfire. Data is kept only as long as needed to stop the abuse.

Rich Presence

The desktop app has a disabled-by-default option to enable "Rich Presence" which shares the name of the project you have open and how long it has been open with chat apps running on your computer, which may be displayed on your public profile. This can be configured in desktop settings.

Loading Projects

When you load a project from another website, you are subject to the privacy practices of that website. For example, when loading projects from Scratch, you are subject to the Scratch privacy policy. When loading projects from Scratch specifically, the project ID will also be shared with TurboWarp as part of Scratch's API does not allow direct access. We may briefly log the project ID for caching.

Cloud Variables

When connecting to our cloud variable servers, the project ID and username may be logged for 14 days. Data in cloud variables is public and sent to anyone else connected at the same time. Custom cloud variable servers are outside of our control.

Extensions

Some extensions must communicate with external APIs to function. For example, the translate and text-to-speech extensions rely on the Scratch API, which is covered by the Scratch privacy policy. To improve performance, some extensions access TurboWarp's APIs instead where both the request (for example, the text being translated) and the result after forwarding to Scratch (for example, the translated version of the text) may be cached.

Most extensions on the official extension gallery will ask for permission when the project attempts to use the extension to access an untrusted website, however we cannot guarantee this is 100% reliable.

When loading a custom extension from a place other than the official gallery such as a URL or file on your computer, the editor will ask for permission to load the extension. If you approve this dialog, the extension can bypass the permission dialogs that official extensions show.

NeoWarp Packager

The integrated copy of the NeoWarp Packager may download files such as Electron binaries from a server controlled by TurboWarp. These downloads will be cached after being downloaded.

When packaging a project using custom extensions, the packager may access those websites to download the extensions.

Packaged Projects

Packaged projects include all scripts, costumes, and sounds to run the project. The packager tries to include all custom extensions too, but in some cases, the packaged project may need to download certain extensions each time it runs.

Advanced features such as third-party custom extensions, custom cloud host, custom JS, and custom CSS are outside of our control.

Note that, unlike the TurboWarp editor, custom extensions in packaged projects will not ask for permission before contacting websites.

You are responsible for informing end users about the privacy practices of the files you distribute. Do not link to this document as your project's privacy policy as it may change in the future. You must write your own.

Local Data

As a desktop application, NeoWarp stores your project files, settings, and cache locally on your computer. Unless you actively initiate a request through the network features above (such as loading an online project or connecting to a cloud variable server), the app will not send your project content to any server.

AI Assistant: When using the AI assistant, your conversation content and project structure information will be sent to the AI service provider you have configured (such as DeepSeek). The handling of this data is governed by the corresponding provider's privacy policy.
